## About This Framework

The Growth AI SEO Audit Framework™ is a structured, evidence-based methodology for auditing, measuring, and improving organic search performance across modern web properties. It integrates traditional search engine optimization with AI search visibility requirements, user experience signals, and conversion intelligence into a single coherent system.

This framework is not a checklist. It is a repeatable, scalable intellectual property system designed for:

- Enterprise SEO audits
- Agency consulting engagements
- Internal team standardization
- Client deliverables
- White-label applications
- Annual benchmark comparisons

---

## Framework Architecture

The framework is organized into nine intelligence pillars. Each pillar governs a distinct domain of search and conversion performance. Together, they produce the Growth AI Score™ — a single composite metric that represents the overall health of a web property across all dimensions.

| Pillar | Domain | Weight |
|--------|--------|--------|
| Technical Intelligence™ | Infrastructure, crawlability, rendering | 20% |
| Content Intelligence™ | Quality, depth, intent alignment | 18% |
| Authority Intelligence™ | Links, trust, digital PR | 12% |
| Entity Intelligence™ | Entities, schema, knowledge graph | 10% |
| AI Visibility Intelligence™ | AI Overviews, LLM readability, SGE | 10% |
| UX Intelligence™ | Core Web Vitals, accessibility, usability | 10% |
| Conversion Intelligence™ | CRO, funnel integrity, landing pages | 8% |
| Analytics Intelligence™ | Measurement, attribution, data quality | 7% |
| Competitive Intelligence™ | Gap analysis, benchmarking | 5% |

## How to Use This Framework

### For SEO Auditors

Begin with `METHODOLOGY.md` to understand the audit workflow. Then work through each chapter sequentially. Each checkpoint in the `/checkpoints/` directory is self-contained and can be assigned to individual team members.

### For Clients and Stakeholders

Begin with `INTRODUCTION.md`, then review `SCORING.md` to understand what the Growth AI Score™ measures and how findings translate to business outcomes.

### For Team Leads

Use the `/templates/` and `/worksheets/` directories to standardize deliverables across engagements. The `/scorecards/` directory contains pre-built scoring instruments for each pillar.

### For Annual Editions

Each version of this framework is tracked in `CHANGELOG.md`. When updating to a new annual edition, review the scoring weights and checkpoint criteria against current Google documentation, Core Web Vitals thresholds, and AI search developments.

## Growth AI Score™ Scale

| Score | Classification | Interpretation |
|-------|---------------|----------------|
| 90 – 100 | Elite | Best-in-class performance across all pillars |
| 75 – 89 | Advanced | Strong performance with minor optimization gaps |
| 60 – 74 | Proficient | Functional performance with clear improvement areas |
| 40 – 59 | Developing | Material gaps affecting visibility and conversion |
| 0 – 39 | Critical | Fundamental issues requiring immediate remediation |
